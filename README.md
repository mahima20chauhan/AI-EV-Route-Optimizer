# 🚗⚡ Intelligent Route Optimization for Autonomous Electric Vehicles

An intelligent route optimization system for Electric Vehicles (EVs) that predicts traffic conditions and suggests the most efficient routes.

## 📌 Features
- Smart route optimization
- Traffic prediction using ML models
- Efficient EV-friendly navigation
- Modular backend + frontend architecture

## 🛠️ Tech Stack
- Frontend: React.js
- Backend: Python (FastAPI)
- Machine Learning: Scikit-learn
- Data Processing & APIs

## 📂 Project Structure
- `frontend/` – User interface
- `backend/` – API & route logic
- `ml_model/` – Traffic prediction model
- `docs/` – Documentation

## 🚀 Future Improvements
- Real-time traffic integration
- Charging station recommendations
- Live map integration
